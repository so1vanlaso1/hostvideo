# Saved generation jobs

These directories are snapshots copied from `/workspace/minimax-h3/jobs`.
They preserve the prompts, API workflows, reference mappings, reports, input
media, and generated clips available when the snapshot was taken. Reports
include completed, failed, and interrupted runs; consult each report for status.

The three-outfit job includes three section clips and `concat.txt` for joining
them, plus the combined `generated.mp4`.

Related dance-project scripts, browser workflows, and review images are saved in
`../projects/dance-outfit-sequence/`. Original absolute paths and ComfyUI upload
names are retained as execution records. To run these jobs on another instance,
adjust asset paths and upload the saved reference media first.

Model weights, Python environments, credentials, and runtime caches are excluded
from the repository. The original runtime directories remain in place.
